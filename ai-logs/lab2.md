## 1. Configurare Mediu si Proiect Vite
- **Solicitare:** Initierea unui proiect React + JavaScript utilizand Vite in folderul app si curatarea fisierelor implicite.
- **Contributie AI:** Ghidarea pentru comanda npm create vite@latest, configurarea ESLint si structurarea directoarelor src/data, src/utils si src/api.

## 2. Exercitiul 1: Date si Functii de Prelucrare pe Liste
- **Solicitare:** Implementarea fisierului src/data/destinatii.js adaptat la proiectul City Explorer si crearea functiilor de prelucrare in utils folosind metode native.
- **Contributie AI:** Scrierea functiilor bazate pe map, filter, reduce si sort pentru a rula corect pe lista de destinatii.

## 3. Exercitiul 2: Imutabilitate si Modificarea Listelor
- **Solicitare:** Implementarea functiilor de modificare a starii fara a altera lista initiala.
- **Contributie AI:** Crearea functiilor de marcare, adaugare si stergere folosind operatorul spread (...) pentru a pastra imutabilitatea, testate prin console.log in main.jsx.

## 4. Exercitiul 3: Consumul unui API Public (Async/Await & Fetch)
- **Solicitare:** Crearea modulului src/api/orase.js pentru interogarea unui server extern si gestionarea erorilor HTTP.
- **Contributie AI:** Implementarea functiilor asincrone cu fetch, tratarea erorilor si afișarea rezultatelor in consola browserului.
